# 1С конфигурация «МебельТорг»

Конфигурация для учёта мебельной торговой компании. Хранится в виде выгрузки
конфигурации в формате Designer (XML), а не в виде `.cf`-файла, поскольку
редактирование ведётся текстово и без запуска графического интерфейса
Конфигуратора.

## Состав

- `Configuration.xml` — корневой файл конфигурации, ссылающийся на дочерние
  объекты.
- `Languages/Language.xml` — язык конфигурации (русский).
- `Catalogs/Номенклатура.xml` — справочник товаров и материалов
  (иерархический, с реквизитами «Артикул», «Единица измерения», «Материал»,
  цены закупки/продажи, ставка НДС, номер ГТД).
- `Catalogs/Контрагенты.xml` — справочник поставщиков и покупателей
  (ИНН, КПП, юридический адрес, контакты, ответственный менеджер).
- `Catalogs/Склады.xml` — справочник мест хранения (адрес, тип склада,
  ответственное лицо).

## Загрузка в информационную базу

Файлы предназначены для пакетной загрузки конфигуратором 1С:Предприятие 8
(`1cv8.exe` / `1cv8`) в режиме `DESIGNER`, без графического интерфейса.

1. Создайте (или используйте существующую) пустую информационную базу.
2. Выполните загрузку конфигурации из файлов каталога:

   ```bash
   1cv8 DESIGNER /F"<путь_к_ИБ>" /N"<пользователь>" /P"<пароль>" \
       /LoadConfigFromFiles "<путь_к_этому_репозиторию>" /UpdateDBCfg
   ```

   Пример для файловой ИБ на Windows:

   ```bat
   "C:\Program Files\1cv8\8.3.XX\bin\1cv8.exe" DESIGNER /F"C:\Bases\МебельТорг" ^
       /N Администратор /LoadConfigFromFiles "C:\src\jumashka" /UpdateDBCfg /Out "C:\Bases\load.log"
   ```

3. Проверьте лог (`/Out`) на отсутствие ошибок.
4. Флаг `/UpdateDBCfg` сразу применяет загруженную конфигурацию к базе данных;
   при необходимости обновление можно выполнить отдельно из Конфигуратора.

## Примечания

- UUID объектов зафиксированы в XML вручную и должны оставаться стабильными
  при последующих изменениях — не меняйте их без необходимости, иначе
  платформа воспримет объект как новый.
- Формы, командные интерфейсы и права доступа в этой выгрузке не заданы —
  добавляются по мере развития конфигурации.
